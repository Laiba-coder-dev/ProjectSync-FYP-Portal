1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Project Compass is an advanced Final Year Project (FYP) management portal 
designed for academic institutions.

Tech Stack:
- Frontend: React 18, TypeScript, Vite
- Styling: Tailwind CSS, shadcn/ui
- Backend (BaaS): Firebase Firebase
- Database: Firebase Firestore
- Storage: Firebase Storage
- Media: Cloudinary (for image uploads)

3. INSTALLATION STEPS
--------------------------------------------------------------------------------
Run the following exact commands in your terminal:

1. Clone the repository:
   $ git clone https://github.com/mrfool05/Project-Compass.git

2. Navigate into the project folder:

6. RUNNING THE APPLICATION
--------------------------------------------------------------------------------
Once dependencies are installed and the exact `.env` file is placed at the root:

1. Start the React/Vite Frontend server:
   $ npm run dev

backend express server to run. The frontend connects directly to the cloud backend.
